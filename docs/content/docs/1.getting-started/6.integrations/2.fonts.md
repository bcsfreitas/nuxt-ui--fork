## Usage

Nuxt UI automatically registers the [`@nuxt/fonts`](https://github.com/nuxt/fonts) module for you, so there's no additional setup required.

### Declaration

Nuxt UI ships with [Allo](https://allo.joshpuckett.me) as its default font, bundled with the library, so it works without any request to a font provider.

To use another font in your Nuxt UI application, you can simply declare it in your CSS. It will be automatically loaded and optimized for you.

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@theme {
  --font-sans: 'Public Sans', sans-serif;
}
```

### Allo axes

Allo is loaded as its full variable font, with three axes:

| Axis | Range | Default | How to change it |
|------|-------|---------|------------------|
| Weight | 100–900 | 400 | The usual `font-*` utilities, e.g. `font-medium` |
| Optical size | 9–32 | follows the font size | `optical-size-9` to `optical-size-32`, back to automatic with `optical-size-auto` |
| Roundness | 0–100 | 50 | `roundness-0` (sharp) to `roundness-100` (round), or `roundness-[80]` |

Set the roundness for the whole app with the `--ui-font-roundness` variable:

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

:root {
  --ui-font-roundness: 80;
}
```

::note
Italic text uses Allo's static oblique files, which have no optical size or roundness axis.
::

### Configuration

You can disable the `@nuxt/fonts` module with the `ui.fonts` option in your `nuxt.config.ts`:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  ui: {
    fonts: false
  }
})
```
